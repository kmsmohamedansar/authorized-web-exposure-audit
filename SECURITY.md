# Security Policy

## Reporting a vulnerability in this project

Use the repository’s private security-advisory feature when available. Otherwise, contact the maintainers privately through a verified project channel before publishing details.

Include:

- A concise description of the issue
- The affected version or commit
- Safe reproduction steps using localhost
- The potential effect on authorization enforcement, data retention, redaction, or network scope
- A suggested mitigation, if known

Do not include live secrets, private records, or data collected from an unauthorized target.

## Target-site findings

This policy covers vulnerabilities in the audit tool itself. Findings about a website belong to that website owner’s approved disclosure process, `security.txt`, vulnerability-disclosure policy, or bug-bounty program. Do not post target findings in this project’s public issue tracker.

## Supported version

Security fixes are applied to the latest version on the default branch. Older snapshots may not receive updates.
